# Smart Finance Project Presentation

Output: `smart_finance_project_presentation.pptx`

Supporting files:
- `presentation_script.md`
- `viva_questions.md`
- `presentation_summary.md`
- `assets/screenshots/`
- `generate_presentation.py`

## Generate

From the project root:

```powershell
python presentation\generate_presentation.py
```

The deck is 16:9 and contains 12 editable slides. All screenshots were captured from the running local dashboard using the repository's sample transaction CSV.

## Edit personal fields

Slide 1 contains placeholders for:
- Student name
- Degree/department
- College name
- Faculty guide
